Workouts recorded with an Apple Watch, or another app that saves workouts to Apple Health, can reach
Dreeve through **[Exerzio](https://exerzio.com/exerzio)**. Exerzio reads the workouts you allow it to
access on your iPhone and uploads them as `.tcx` files through Dreeve's HTTP API.

```text
Apple Watch or workout app
  → Apple Health on iPhone
  → Exerzio → your Dreeve server
```

## Exerzio for iPhone

**Exerzio is free to download and use, including Dreeve sync.** There is no subscription or Exerzio
account to create. Optional Tip Jar purchases support development and do not unlock features.

The app gives you a view of the activity already on your iPhone:

- **Workout history and detail:** browse your sessions, personal records, routes and available
  heart-rate, cadence and power readings.
- **Atlas and Tiles:** see your recorded routes together on one map, or explore a grid of squares
  that tracks the places you have covered during workouts.
- **Daily activity and sleep:** review steps, energy, workouts and sleep from Apple Health.
- **Sharing:** turn workouts, routes and activity summaries into cards with Create Studio.

Dreeve sync is an optional part of that app. You can keep recording with Apple Watch or your usual
workout app: once a supported workout reaches Apple Health on your iPhone, Exerzio can read it and
send it to Dreeve. You do not need to record it again in Exerzio or export an Apple Health archive.

## What gets sent

Choose **Running**, **Cycling**, **Walking** or **All** in Exerzio's **Workout types** setting.
These groups also cover treadmill running, indoor and hand cycling, and hiking.

Exports include the workout's timing and distance, plus available route, heart-rate, elevation,
cadence and power data that Exerzio can read from Apple Health. A workout can be sent without a
GPS route. Data that was not recorded or is not readable in Health cannot be added to the export.

This connection sends workouts to Dreeve. It does not transfer your sleep history or daily step
totals, or copy Dreeve activities back into Apple Health.

## Setup

### 1. Prepare Dreeve

Use **Dreeve 5.3.0 or newer** in [file import mode](/importing/file-import/), with a server address
your iPhone can reach. Use HTTPS for a remote server.

1. In Dreeve's admin panel, open **Settings → Security → API access** and generate an API key.
2. Set the generated key as `DREEVE_API_KEY` in your server's `.env` file. Ensure
   `IMPORT_MODE=files` is selected.
3. Recreate the containers to apply the environment changes:

```bash
> docker compose up -d --force-recreate
```

Keep the API key private. See the [HTTP API documentation](https://docs.dreeve.app/api/) for more about API access.

### 2. Connect Exerzio

1. Install Exerzio on your iPhone and allow it to read the workouts and associated Health data
   you want to send.
2. Open **Settings → Data Sources → Dreeve** in Exerzio.
3. Enter your full Dreeve installation address, for example `https://dreeve.example.com`.
   Include any installation subpath, such as `https://example.com/dreeve`, but do not append `/api/v1`.
4. Paste the same API key you configured on the server and tap **Connect to Dreeve**.
5. Choose the **Workout types** you want to send.

Exerzio checks the server, API key, Dreeve version and upload availability when connecting.
For a server on your home network, your iPhone must be able to reach it, and you may need to allow
Local Network access. A `.home.arpa` address requires HTTPS with a certificate your iPhone trusts.

### 3. Send your workouts

- **Sync now** sends eligible new workouts on demand.
- **Automatically send new workouts** enables automatic sync. Background delivery follows iOS
  scheduling and depends on the server being reachable; it is not an immediate delivery guarantee.
- **Send earlier workouts…** imports older history. Choose **Last 7 days**, **Last 30 days**,
  **This year** or **All available workouts**. Earlier workouts are only sent when you request them.

Exerzio remembers which workouts it has already sent to each server. Dreeve also applies its
[duplicate detection](/importing/file-import/#duplicate-detection) during import.

:::note[Queued is not yet imported]
**Queued in Dreeve** means the server has accepted the upload, not that the activity has finished
importing. Dreeve processes it asynchronously. Check the **file import log** at `/admin/file-imports`
for the final result and the imported activity.
:::

## If a workout does not appear

- Check the connection status in Exerzio. If it says **API key required**, use
  **Reconnect to Dreeve** and re-enter the key.
- Check that the workout is in Apple Health, Exerzio has read access and its type is selected.
  For an older workout, use **Send earlier workouts…**.
- Review **Needs attention** in Exerzio for workout-specific errors and retry options.
- If the upload was accepted, check Dreeve's [file import log](/importing/file-import/#the-import-log)
  for a successful, skipped or failed import. A skipped duplicate may already be in your activities.

## Privacy and disconnecting

Sync is optional. Selected workouts travel directly from your iPhone to the Dreeve server you
configure, without passing through an Exerzio server. The API key is stored in the iPhone's Keychain.

Disconnecting in Exerzio stops delivery and removes the saved key from that iPhone. Workouts already
in Dreeve and the originals in Apple Health remain in place. To revoke the server's API key too,
remove `DREEVE_API_KEY` from its environment and recreate the containers.
